## Entry

The entry is a single line (1 to 240 characters) that the Moon says back to everyone who has ever stared up at it. It lives in `entry.txt`.

## How to run

```sh
python3 main.py
```

`main.py` copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`).
